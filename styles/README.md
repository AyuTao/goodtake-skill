# GoodTake 风格资产库（`styles/`）

本目录保存可跨项目复用的**视频视听风格预设（Style DNA）**。每套风格以单个 `.json` 文件描述，涵盖配色方案、字体与字幕、电影画幅与光效、视觉介质配比、剪辑节奏、配乐调性及防裁切封面规范。

## 工作闭环

1. **开拍前选用（阶段 0）**：
   - 运行 `node ../scripts/save_style_preset.mjs --list` 查看全部已有风格；
   - 在对话中直接指定风格名（例如：`/goodtake 用「黑曜石熔金」风格做一期……`），即可让整个系列视频保持高度一致的电影频道感。
2. **完工后沉淀（阶段 8 后置闭环）**：
   - 每条视频验收完成后，GoodTake 会主动询问用户：**「要不要把这版的视觉调性、配色字体、剪辑节奏、配乐气质和封面风格保存成一套复用风格，下次直接套用？」**
   - 用户确认并命名后，自动通过 `scripts/save_style_preset.mjs --save` 提炼参数存入本目录 `styles/<slug>.json`（严禁写入任何私密路径或个人密钥）。
