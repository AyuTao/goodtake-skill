# 导演分镜与视觉美学圣经（Director's Bible）

本手册总结了从「静态 PPT 式科普（失败反例）」升级为「院线级 60+ 镜头电影科普（V3 基准）」的全部导演方法论。

---

## 一、为什么普通 AI 科普视频看起来“不震撼”？（血泪反例复盘）

| 反例病灶 | 观众观感 | V3 导演级根治方案 |
|---|---|---|
| **单镜死顶 30–50 秒** | 像听老师讲 PPT，5 秒就划走 | 拆分 **50–70 个独立镜头**，平均 **4.0–5.5 秒/镜**，单镜绝不超过 7.5 秒 |
| **满屏黑底细线框前端卡片** | 像写后台管理系统的网页截图 | 彻底取消圆角卡片和密集小字；改用 **程序真动画（Three.js / Remotion / GSAP / Canvas / SVG）+ 真实一手素材包装 + 极少（0–3 个）必要奇观镜** |
| **无景别与运镜变化** | 画面僵硬、缺少情绪起伏 | 每镜配置独立推/拉/摇/移轨迹（`s0→s1, x0→x1, y0→y1`）+ 低音冲击微震 + 闪白/黑切转场 |
| **图与词脱节** | 旁白说到关键概念时画面没反应 | 提取逐词毫秒时间戳 `syncCues`，念到某个数字、拐点、转折时画面在 **±20ms** 内同步触发 |
| **花哨无规律配色** | 杂乱廉价，缺少电影高级感 | 全片锁死单一主视觉色系（如黑曜石 + 熔金），仅在语义突变处用单一高能辅色（赤红警报 / 翡翠验证绿 / 冰蓝曲线） |

## 二、克制用图铁律与视觉介质优先级（少用图片，非必要不生图！）

**核心审美升级：彻底拒绝“靠 10+ 张 AI 静图平移拼凑整条视频”的偷懒做法！**
硬核科普与知识视频最顶级的质感，来自**精密流畅的程序真动画**与**真实一手素材**；AI 概念图/AI 视频只用在真正不可替代的情感奇观节点（**全片克制在 0–3 张/段**）。

### 四大视觉介质严格优先级配比

1. **【第一主力 · 占比 60%–75%】纯代码程序真动画 & 电影级动效排版（优先用它！）**
   - 用途：所有原理推演、数学公式、曲线演化、波形示波、时间轴、对比拆解、流程架构、大字撞击与数据计数。
   - 工具：**Three.js WebGL 3D 实时场景、Remotion `spring()` 物理动效、GSAP 弹性时间轴、SVG `stroke-dashoffset` 路径生长、Canvas 实时仿真、Manim 数学动画**，所有演化关键节点毫秒级绑定 `syncCues`。
   - 审美：深黑聚光灯舞台（`#030407`）+ 细腻径向光晕 + 变形镜头拉丝眩光 + 景深微粒，内容主舞台锁定在 `y = 110..865`，绝不侵入底部字幕区。
2. **【第二主力 · 占比 15%–25%】真实一手证据素材（App 截图 / 实机录屏 / 原论文扫描）**
   - 用途：工具/软件/教程类题材展示真实 App 界面（如本机创作或发布工具的工作台截图）、真实终端运行、原始论文或一手数据图表——**有真实画面，可信度翻十倍！**
   - 包装铁律：**严禁硬贴白底整屏截图！** 统一置于暗房 3D 微透视玻璃相框内，叠加环境暗角投影与移动聚光放大镜（只高亮当前旁白讲到的核心区域），并自动隐藏/打码账号隐私。
3. **【克制点睛 · 占比 0%–15%，非必需不用！】AI 动态视频（I2V/T2V）或极少数电影原画（0–3 个核心奇观镜）**
   - **少用图片铁律**：凡是程序动画、3D 镜头或真实截图能讲清楚的镜头，**一律不生图**！
   - 仅在全片 **1–3 个最宏大的隐喻/高潮定场点**（如开场震撼奇观、跨维破局瞬间、终章史诗意象），生成极少量统一光影锚点的高清画面，且**优先用视频模型（如冰爪 `generate_video` FastH3 / MiniMax H3 首帧图生视频或首尾帧变身）让其真正动起来**！
   - 若生成概念原画，每张必须共享同一摄影光影锚点并强制加上 `strictly no text, no letters, no numbers, no watermark`。

## 三、全平台防裁切封面设计规范（一图通吃绝不腰斩！）

> **致命避坑**：绝不能随手截取正片某一帧当封面！16:9（`1920×1080`）封面发到不同平台会被强制二次裁切：
> - **视频号 / 抖音主页 / 小红书推荐流**：强制裁取中心 **`3:4`（`810×1080`）**、**`6:7`（`926×1080`）** 或 **`1:1`（`1080×1080`）**，左右两边各会直接切掉 **22%–29%（约 `420–555px`）**！
> - **B站 / YouTube / 抖音横屏**：显示 `16:9`，但**右下角 `220×90px`** 会被时长角标（如 `04:55`）遮挡，顶部与底部约 `110px` 易被状态栏或标题栏压住。

### 封面黄金安全区精确像素铁律（`1920×1080` 基准）
1. **核心标题与视觉主体死锁区（Universal 3:4 Safe Core）**：
   - **水平范围：`x ∈ [585, 1335]`（最大宽度 ≤ `750px`，居中对称，左右各留白 ≥ `585px`！）**
   - **垂直范围：`y ∈ [140, 920]`（上下各留白 ≥ `140px`，避开顶栏、底栏与播放条！）**
   - 只要把**全部封面标题文字、核心数字和视觉焦点**收束在这块 `750 × 780 px` 黄金核心区内，无论平台裁成 `16:9`、`1:1`、`6:7` 还是最苛刻的 `3:4` 竖框，**封面标题 100% 完整居中，绝不被裁掉哪怕半个字！**
2. **封面必须自带大字标题（独立渲染，零正片字幕）**：
   - 主标题采用 **2–3 行居中紧凑堆叠**，每行严格控制在 **4–7 个大字**（字号 `108px–142px` 粗体），严禁横贯整屏的单行长标题！
   - 副标钩子 1 行（≤ `12 字`，字号 `38px–46px`），紧贴主标下方且同样锁死在 `750px` 宽度内；
   - 标题背后必须有深色径向聚光压暗 + 细腻外描边，保证手机信息流缩略图（拇指大小）0.3 秒一眼读清！
3. **封面防限流合规**：严禁出现竞品平台名、诱导点击词或虚假夸大承诺。
4. **强制四比例裁切亲眼审计**：封面生成后，**必须运行 `scripts/verify_cover_safezone.mjs <cover.jpg> <audit.jpg>`**，生成带 `16:9 / 1:1 / 6:7 / 3:4` 安全线与四平台真实裁切模拟拼图的审计图，**亲眼 `read_file` 确认全部 4 种比例下标题完整无裁切、不压右下角时长角标**，才算验收通过！

## 四、电影光学与转场语言

| 转场代号 | 时长与视觉动作 | 适用场景 | 搭配音效 |
|---|---|---|---|
| `flash_cut` | 首 `200ms` 暖白曝光过冲衰减（`rgba(255,245,222,0.62→0)`） | 章节开篇、重要概念揭晓、视觉升级 | `boom` / `boom_soft` |
| `drop_boom` | 前镜末 `200ms` 真空吸气 + 首 `300ms` 高能闪白（`0.88→0`）+ 强镜头微震 | 全片 2–3 个核爆级高潮（如危机失控、跨维破局） | `riser_epic` + 200ms Drop + `mega_boom` |
| `hard_black` | 首 `68ms`（2 帧）纯黑快门顿挫 | 日期切换、视角反转、切入数学实验室、档案快切 | `shutter`（胶片快门咔嗒） |
| `fade_cut` | `450ms` 柔暗叠化 | 历史跨度过渡、情绪沉静回归、片尾收束 | `sub_swell` / `piano_solo` |

- **宽银幕画框**：上下各加 `44px` 纯黑边（约 `2.15:1` 院线呼吸感），瞬间剥离普通 16:9 录屏感。
- **变形镜头拉丝眩光（Anamorphic Lens Flare）**：在主标题或关键公式下缘绘一道极细横向渐变光丝，随 BPM 节拍脉冲呼吸。
- **景深空气尘埃**：70–80 颗确定性伪随机漂浮粒子，随幕次情绪切换色调（琥珀金 / 冰蓝 / 警报红 / 翡翠绿）。

## 五、数学与科学可视化的出版级铁律

1. **100% 真实数值计算**：绝不手绘假曲线！阶梯函数、对数积分、显式公式叠加、统计分布一律用真实数值算法在渲染脚本中精确算出。
2. **严禁使用 Unicode 上标字符（`ˢ` `⁻` `¹`）排版公式**：在 macOS 中文字体中，Unicode 上标负号与字母基线高度参差不齐，极易歪斜。必须使用自定义分段排版函数 `drawMathFormula(segments, ...)`，将上标/下标用 `0.52×` 字号沿基线精确偏移 `-0.34×` / `+0.30×` 绘制，达到 LaTeX 论文印刷级水准。
3. **超大清晰字号规范（1920×1080 基准）**：
   - 砸屏巨字/核心数字：`140px – 300px`
   - 章节/主标题：`94px – 138px`
   - 数学公式主字：`62px – 132px`
   - 坐标轴数字与拐点标注：`24px – 30px`（高对比亮色，绝不与曲线交叉遮挡）
   - 底部电影字幕：`42px` 粗黑/圆体纯白 + `8px` 深黑外描边 + 柔暗投影（**绝不加半透明丑黑条**）
